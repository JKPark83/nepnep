## 수동 회귀 (R1~R10)

| # | 시나리오 | 확인 항목 | 결과 | 비고 |
|---|---|---|---|---|
| R1 | 1h 녹음 → 처리 → 전사·요약 | 잠금화면·전화 인터럽트 구간이 gapRanges로 기록되고, 처리 후 전사·화자·요약이 모두 생성됨 | ☐ | |
| R2 | 강제 종료 복구 | 녹음 중 강제 종료 → 홈에 복구 배너, 처리 중 강제 종료 → 재실행 시 체크포인트부터 재개 | ☐ | |
| R3 | 화자 이름 지정·합치기·검색 | 이름 지정 반영, 합치기 후 되돌리기 동작, 검색이 제목+전사 본문을 모두 찾음 | ☐ | |
| R4 | Notion·Google 내보내기 | 각 대상 연결 → 내보내기 → 같은 회의 재내보내기 시 기존 페이지/문서 갱신, 자동 내보내기가 연결된 모든 대상으로 전송 | ☐ | Google은 OAuth 클라이언트 ID 등록 후 가능 |
| R5 | 구매·복원·페이월 3진입점 | 녹음 화면 클라우드 토글 / 설정 / 처리 실패 폴백에서 페이월 진입, 구매 후 프로 배지, 복원 동작 | ☐ | Sandbox 테스터 필요 |
| R6 | 클라우드 처리 E2E | 업로드 → RTZR → 요약 → 사용량 차감, 쿼터 초과(402) 시 기기 처리 폴백 | ☐ | 서버 env 설정 후 가능 |
| R7 | 오디오만 삭제 | 완료된 회의의 오디오만 사라지고 회의록은 유지, 발화 재생 비활성 | ☐ | |
| R8 | 온보딩 첫 실행 | 앱 삭제 후 재설치 → 가치 3장 → 권한 2건 요청 → 모델 다운로드 → 홈 빈 상태. 마이크 거부 시 녹음 시작에서 설정 앱 유도 | ☐ | |
| R9 | 배터리·발열 | 1h 녹음 배터리 소모 ≤10%, 30분 처리 중 thermalState가 `serious` 미만 | ☐ | |

> 원 계획(09-m6 §5)의 R9 "엔진 전환"은 WhisperKit 제거로 삭제했다. 전사 엔진은 SpeechTranscriber 하나뿐이다.
