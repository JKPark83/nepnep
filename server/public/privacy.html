넵넵 개인정보 처리방침

시행일: 2026년 9월 1일

1. 기본 원칙 — 온디바이스 처리

넵넵의 무료 기능(녹음, 전사, 화자 구분, 요약)은 모두 사용자의 기기 안에서 실행됩니다. 녹음 파일, 전사 내용, 요약은 기기 밖으로 전송되지 않으며, 넵넵은 이를 수집하지 않습니다.

2. 클라우드 고품질 처리(프로 구독) 이용 시

사용자가 클라우드 처리를 선택한 경우에만 오디오 파일이 암호화(TLS)되어 서버로 전송됩니다. 서버는 전사·요약 처리를 마친 뒤 오디오와 전사 데이터를 즉시 폐기하며, 저장하지 않습니다. 이 과정에서 다음 외부 위탁사를 이용합니다: 리턴제로(음성 인식), Anthropic(요약 생성), Vercel(서버 호스팅·임시 파일 저장).

3. 구독 관리

프로 구독 상태 확인과 월 사용량 관리를 위해 Apple이 발급하는 비식별 거래 식별자 (originalTransactionID)와 사용량(처리한 오디오 길이)만 서버에 보관합니다. 이름, 이메일 등 계정 정보는 수집하지 않으며 별도의 회원 가입도 없습니다.

4. 외부 서비스 연동(Notion, Google Docs)

사용자가 직접 연동하고 내보내기를 실행한 경우에만 회의록 텍스트가 해당 서비스로 전송됩니다. 연동 인증 토큰은 사용자 기기의 iOS 키체인에만 저장됩니다.

5. 데이터 삭제

모든 회의 데이터는 기기에 저장되므로 앱 안에서 삭제하거나 앱을 삭제하면 함께 제거됩니다. 서버에 보관되는 구독 식별자·사용량 정보의 삭제를 원하시면 아래 연락처로 요청해 주시기 바랍니다.
